# Contributing to Nexora SAGE

Issues, reproducible bug reports, design discussion, and review feedback are
welcome.

External copyrighted contributions, including code, tests, fixtures,
evaluation data, and substantial documentation, are not currently accepted
or merged. This keeps the rights boundary honest while contribution terms
remain unresolved.

Do not submit secrets, private repository content, personal data, customer
data, or material you are not authorized to disclose.
