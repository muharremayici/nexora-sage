# Nexora SAGE v1 Release Boundary

Nexora SAGE v1 is an AI-era architectural governance release with a React/TypeScript surgical specialization.

## Strong v1 Claims

- React/TypeScript architecture analysis is the deepest supported surface.
- ContextOS gives AI agents a watchdog-first live focus window, first-ring halo, breadcrumbs and reverse trace.
- MCP/HITL surfaces let agents inspect, validate patches and request human approval before risky actions.
- Atlas/Genome preserve raw DNA and logic-first DNA for TypeScript/React symbols.
- State/data evidence propagates through imported custom hooks so consumer components inherit Zustand/TanStack boundary signals from hook providers.
- Test Gap Report v1 gives agents a prioritized test-selection and coverage-risk surface.
- React fixture evidence is required and currently covers current workspace, Vite, Next/App Router and router-oriented fixture artifacts.

## Conservative v1 Claims

- Python support is AST-backed and stronger than the rest of the non-TS substrate.
- Java, Go and C# support is structural symbol/import extraction, not compiler-grade semantic governance.
- Runtime-only React behavior is surfaced with confidence and runtime-proof expectations; v1 does not claim full runtime determinism.
- A truly exhaustive React claim requires v2 runtime probes for render paths, provider tree reachability, Zustand mutations/selectors, TanStack query lifecycle, lazy route branches and hydration/client-server behavior.

## Out of Scope for v1

- VS Code/LSP extension.
- First-class GitHub Action marketplace package.
- Production browser/runtime tracing probes.
- Tree-sitter or language-server based semantic parity for every language.

## Distribution Proof Boundary

Clean-machine transcript evidence is not part of the React/TypeScript static
governance claim itself. It is a distinct public-release hardening proof because
it answers a different question: whether the source distribution installs and
runs from a fresh environment.

The public candidate is built only after the frozen development source has
been synchronized into a committed clean-install delivery. The sync-generated
delivery identity binds the clean tree to the canonical source commit, complete
file count and projection SHA-256; a folder name or human note alone is not
release-source authority.

## v1 Proof Boundary

The v1 source identity was accepted only after the complete frozen-source
machine proof, manual agent-surface review, clean distribution validation and
independent clean-machine installation evidence passed their declared gates.
Release-facing text language hygiene is part of the frozen-source machine proof.
Those maintainer proofs do not need to run during ordinary target-repository
analysis and do not certify an arbitrary target repository.

## Public Positioning Sentence

Nexora SAGE v1 is a living architecture atlas, governance engine and AI-agent safety layer for React/TypeScript systems, built on a modular polyglot substrate.
